# Daily English Dictionary

Personal vocabulary journal: **10 words + 10 phrases** every day, with meaning and usage.

## Layout

```
daily/
  YYYY-MM-DD.md   # one file per day
INDEX.md          # running list of all dates + counts
```

## Entry format

Each daily file includes:

- Date heading
- **Words (10)** — meaning + one natural usage sentence each
- **Phrases (10)** — meaning + one natural usage sentence each

## Automation

A Cursor Automation runs **every day at 8:00 AM (IST)** and appends a new dated file without repeating recent entries.
